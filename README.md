# Toolbank

Free online toolbox with word counter, text-to-speech, speech-to-text, PDF converter, QR code & password generators, BMI, EMI, age and percentage calculators, and unit converter. No signup or download — runs instantly in your browser.

**Live site:** https://toolbank.github.io/toolbank/

## Tools included

- Word & Character Counter
- Text Case Converter
- Text → Speech
- Speech → Text
- Text Similarity Checker
- Password Generator
- QR Code Generator
- BMI Calculator
- Unit Converter
- Text → PDF
- Images → PDF
- PDF → Text
- Age Calculator
- Percentage Calculator
- Loan / EMI Calculator
- Discount Calculator

## How it works

Everything runs client-side in plain HTML, CSS, and JavaScript. No backend, no server, no data ever leaves the browser (except the QR, PDF, and speech libraries loaded from public CDNs).

## Running locally

Just open `index.html` in any modern browser — no build step required.
